# nepub-reader

小説家になろう・カクヨムの作品を縦書き表示で快適に読めるリーダーです。

## 特徴

- 縦書き表示で小説家になろう・カクヨムの作品を読める
- ダークモード対応（システム設定に連動。ライト / セピア / ダークの手動切り替えも可）
- 最後/最初のページから先へ進むと、次/前のエピソードへ自動で移動
- 読書履歴機能（最近読んだ作品をトップページに表示し、続きから再開。別の PC へはエクスポート / インポートで読書位置ごと移せる）
- リモコン操作でもページが飛ばない（1 回押すごとに 1 ページ）

## セットアップ

### 必要なもの

- Python 3.11 以上
- uv（Python パッケージマネージャー）

### インストール

```bash
uv sync
```

### サーバー起動

```bash
uv run nepub-reader
```

ブラウザで http://localhost:5000/ にアクセスしてください。

### Docker で起動

```bash
# ビルド
docker build -t nepub-reader .

# 実行（この PC からだけ使う場合。LAN 内のほかの端末から使うなら -p 5000:5000）
docker run -p 127.0.0.1:5000:5000 nepub-reader
```

キャッシュを永続化したい場合はボリュームをマウントしてください：

```bash
docker run -p 5000:5000 -v nepub-cache:/app/epub-cache nepub-reader
```

## 使い方

トップページのフォームに小説家になろうまたはカクヨムのURLを入力して「読む」ボタンを押します。

- **小説家になろう**
  - 話の URL（`https://ncode.syosetu.com/nXXXXXX/1/`）→ その話から開始
  - 作品ページの URL（`https://ncode.syosetu.com/nXXXXXX/`）→ 1 話から開始
- **カクヨム**
  - 話の URL（`https://kakuyomu.jp/works/XXXXX/episodes/XXXXX`）→ その話から開始
  - 作品ページの URL（`https://kakuyomu.jp/works/XXXXX`）→ 最初の話から開始

### 操作方法

| 操作 | 動作 |
| --- | --- |
| ← / → | 左 / 右へページをめくる（縦書きなら ← が次のページ） |
| ↓ / PageDown / Space | 次のページ |
| ↑ / PageUp / Shift+Space | 前のページ |
| ページの左 1/3・右 1/3 をクリック（タップ） | 左 / 右へページをめくる |
| 左右にスワイプ | 指で引いた方向へページをめくる（右へスワイプすると左のページ） |
| マウスホイール・トラックパッド | 下へで次のページ、上へで前のページ（横方向は ← / → と同じ）。1 回の操作で 1 ページ |
| 最後のページで次へ / 最初のページで前へ | 次の話 / 前の話（の最後のページ）へ移動 |
| ツールバーの「Aa」 | 表示設定を開く（文字サイズ、フォント、行間、表示幅、表示方向、テーマ。横書きにしたときは見開きも）。開いている間はキーでページがめくれない（Esc か外側のクリックで閉じる） |
| ツールバーの「前の話」「次の話」 | 前の話 / 次の話の先頭へ移動 |
| ツールバーの「トップ」 | トップページへ戻る |
| ページの中央をクリック（タップ） | ツールバーを隠す / 出す（隠した分だけページが広がる） |

表示の設定と、作品ごとに最後に読んだ話の読書位置はブラウザ（localStorage）に保存されます。トップページの配色は、リーダーで選んだテーマに合わせて変わります。

## キャッシュ

生成された EPUB ファイルは `epub-cache/` ディレクトリにキャッシュされます。キャッシュを削除したい場合は、このディレクトリ内のファイルを削除してください。
