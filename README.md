# nepub-reader

小説家になろう・カクヨムの作品を縦書き表示で快適に読めるリーダーです。

## 特徴

- 縦書き表示で小説家になろう・カクヨムの作品を読める
- ダークモード対応（システム設定に連動。ライト/ダークの手動切り替えも可）
- 最後/最初のページから先へ進むと、次/前のエピソードへ自動で移動
- 読書履歴機能（最近読んだ作品をトップページに表示し、続きから再開）
- リモコン操作でもページが飛ばない（1 回押すごとに 1 ページ）

## セットアップ

### 必要なもの

- Python 3.10 以上
- uv（Python パッケージマネージャー）

### インストール

```bash
uv sync
```

### サーバー起動

```bash
uv run nepub-reader
```

ブラウザで http://localhost:5000/ にアクセスしてください。

### Docker で起動

```bash
# ビルド
docker build -t nepub-reader .

# 実行
docker run -p 5000:5000 nepub-reader
```

キャッシュを永続化したい場合はボリュームをマウントしてください：

```bash
docker run -p 5000:5000 -v nepub-cache:/app/epub-cache nepub-reader
```

## 使い方

トップページのフォームに小説家になろうまたはカクヨムのURLを入力して「読む」ボタンを押します。

- **小説家になろう**
  - エピソードURL（`https://ncode.syosetu.com/nXXXXXX/1/`）→ その話から開始
  - 小説トップURL（`https://ncode.syosetu.com/nXXXXXX/`）→ 1話から開始
- **カクヨム**
  - エピソードURL（`https://kakuyomu.jp/works/XXXXX/episodes/XXXXX`）

### 操作方法

| 操作 | 動作 |
| --- | --- |
| ← / → | 左 / 右へページをめくる（縦書きなら ← が次のページ） |
| ↓ / PageDown / Space | 次のページ |
| ↑ / PageUp / Shift+Space | 前のページ |
| ページの左 1/3・右 1/3 をクリック | 左 / 右へページをめくる |
| 最後のページで次へ / 最初のページで前へ | 次の話 / 前の話（の最後のページ）へ移動 |
| ツールバー | 目次、文字サイズ（A− / A＋）、フォント、表示幅、表示方向、テーマの変更、トップページへ戻る |

マウスホイール・トラックパッド・スワイプでのページ送りには対応していません。

表示の設定と、作品ごとに最後に読んだ話の読書位置はブラウザ（localStorage）に保存されます。

## キャッシュ

生成された EPUB ファイルは `epub-cache/` ディレクトリにキャッシュされます。キャッシュを削除したい場合は、このディレクトリ内のファイルを削除してください。
