# nepub-reader

小説家になろう・カクヨムの作品を縦書き表示で快適に読めるリーダーです。

## 特徴

- 縦書き表示で小説家になろう・カクヨムの作品を読める
- ダークモード対応（システム設定に連動。ライト / セピア / ダークの手動切り替えも可）
- 最後 / 最初のページから先へ進むと、次 / 前の話へ自動で移動
- スマートフォンでも読める（タップ・スワイプでのページ送り、画面に合わせた文字サイズ。ブラウザの「ホーム画面に追加」で、アドレスバーのない全画面で開ける）
- 読書履歴機能（直前に読んでいた作品と、これまでに読んだ作品をトップページに表示し、続きから再開。作品名で絞り込める。別の PC へはエクスポート / インポートで読書位置ごと移せる）
- リモコン操作でもページが飛ばない（1 回押すごとに 1 ページ）

## セットアップ

### 必要なもの

- Python 3.11 以上
- uv（Python パッケージマネージャー）

### インストール

```bash
uv sync
```

### サーバー起動

```bash
uv run nepub-reader
```

ブラウザで http://localhost:5000/ にアクセスしてください。既定では、この PC からしか使えません。LAN 内のほかの端末から使う場合は、環境変数 `HOST=0.0.0.0` を指定して起動します（ポートは `PORT` で変えられます）。

### Docker で起動

```bash
# ビルド
docker build -t nepub-reader .

# 実行（この PC からだけ使う場合。LAN 内のほかの端末から使うなら -p 5000:5000）
docker run -p 127.0.0.1:5000:5000 nepub-reader
```

キャッシュを永続化したい場合はボリュームをマウントしてください：

```bash
docker run -p 127.0.0.1:5000:5000 -v nepub-cache:/app/epub-cache nepub-reader
```

## 使い方

トップページのフォームに小説家になろうまたはカクヨムの URL を入力して「読む」ボタンを押します（先頭の `https://` は省けます）。

読んだことのある作品は、トップページの「続きを読む」と読書履歴から、読んでいた位置で開けます（パソコンでは、トップページを開いてすぐ Enter を押すと、直前に読んでいた作品の続きが開きます）。

- **小説家になろう**
  - 話の URL（`https://ncode.syosetu.com/nXXXXXX/1/`）→ その話から開始
  - 作品ページの URL（`https://ncode.syosetu.com/nXXXXXX/`）→ 1 話から開始
  - 短編（話に分かれていない作品）は、作品ページの URL で開けます
  - 作品情報のページの URL（`https://ncode.syosetu.com/novelview/infotop/ncode/nXXXXXX/`）でも、1 話から開けます
  - ノクターンノベルズなど（`novel18.syosetu.com`）の作品には対応していません
- **カクヨム**
  - 話の URL（`https://kakuyomu.jp/works/XXXXX/episodes/XXXXX`）→ その話から開始
  - 作品ページの URL（`https://kakuyomu.jp/works/XXXXX`）→ 最初の話から開始

### 操作方法

| 操作 | 動作 |
| --- | --- |
| ← / → | 左 / 右へページをめくる（縦書きなら ← が次のページ） |
| ↓ / PageDown / Space | 次のページ |
| ↑ / PageUp / Shift+Space | 前のページ |
| ページの左 1/3・右 1/3 をクリック（タップ） | 左 / 右へページをめくる |
| 左右にスワイプ | 指で引いた方向へページをめくる（右へスワイプすると左のページ） |
| マウスホイール・トラックパッド | 下へで次のページ、上へで前のページ（横方向は ← / → と同じ）。1 回の操作で 1 ページ |
| 最後のページで次へ / 最初のページで前へ | 次の話 / 前の話（の最後のページ）へ移動。最新話では「最新話です」と出るので、新しい話が公開されたら「再確認」を押す |
| ツールバーの下の線のつまみ | ドラッグして離すと、その話の中のその位置へ移動。線は読み終えた分だけ塗られる（縦書きでは右から進む） |
| ツールバーの「Aa」 | 表示設定を開く（文字サイズ、フォント、行間、表示幅、余白、表示方向、テーマ。横書きにしたときは見開きも）。開いている間はキーでページがめくれない（Esc か外側のクリックで閉じる） |
| ツールバーの「前の話」「次の話」、P / N キー | 前の話 / 次の話の先頭へ移動 |
| ツールバーの「トップ」 | トップページへ戻る |
| ツールバーの「元ページ」 | 読んでいる話を、元サイト（小説家になろう / カクヨム）で開く（狭い画面では表示されない） |
| ページの中央をクリック（タップ） | ツールバーを隠す / 出す（隠した分だけページが広がる。隠したかどうかは次に開いたときも保たれる）。隠している間は、画面の上の端の細い線と、下の中央の「ページ / 全ページ（%）」で、どこまで読んだかが分かる。マウスを画面の上の端に寄せると、寄せている間だけツールバーが出る |

文字サイズの初期値は、スマートフォンなどの狭い画面（横向きを含む）では小さめ（24px）、それ以外では大きめ（45px）です。「Aa」から変えられます。

表示の設定と、作品ごとに最後に読んだ話の読書位置はブラウザ（localStorage）に保存されます。トップページの配色は、リーダーで選んだテーマに合わせて変わります。

## 開発

テストは Docker で実行します（ホストに Python や Node.js は要りません）。構成や設計のメモは [CLAUDE.md](CLAUDE.md) にまとめています。

```bash
docker build -t nepub-reader .
# サーバーのテスト
docker run --rm -v "$PWD:/src:ro" -w /src nepub-reader /app/.venv/bin/python -B -m unittest discover -s tests
```

## キャッシュ

生成された EPUB ファイルは `epub-cache/` ディレクトリにキャッシュされます。合計が 1 GB を超えると、長く読まれていない話から自動で削除されます。手動で削除したい場合は、このディレクトリ内のファイルを削除してください。

以前の版が作ったキャッシュ（`epub-cache/` 直下の `narou/`・`kakuyomu/`）は、起動時に削除されます（作品名が正しく入っていないものがあるため。読むときに作り直されます）。
